# Laplace-and-Exponential-mechanisms-for-privacy
********************************************************************************************************************************

Project objective 

Application of Laplace and Exponential mechanisms to add random noise to data for differential privacy. 

********************************************************************************************************************************
Description

1.) Add random noise to data for differential privacy by applying Laplace and Exponential mechanisms.

2.) Plotting MSE (Mean Squared Errors) vs. epsilon.

********************************************************************************************************************************


Input dataset:
Adult dataset from UCI ML Repository. 
However, the mechanisms could be applied to any existing or newly generated dataset.


********************************************************************************************************************************

Getting Started

Dependencies

There are no additional dependencies to install. 
The package includes all files, and the code makes all necessary imports.

-> Simply fork the repository and run it as any Python project.
